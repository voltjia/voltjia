# Contributing

This repository contains the profile README for [@voltjia](https://github.com/voltjia). It is intentionally small, and its contribution process should remain lightweight.

## Workflow

- Create short-lived branches from `main`.
- Use `docs/<topic>` for profile and documentation changes.
- Use `chore/<topic>` for repository maintenance and templates.
- Use `ci/<topic>` for automation.
- Keep each pull request focused on one logical change.
- Use pull requests for substantive changes. Minor typo fixes may be committed directly to `main`.

## Commit Messages and Pull Request Titles

Use the following format:

```text
<type>: <summary>
```

Allowed types:

- `docs` for profile and documentation changes.
- `chore` for repository maintenance.
- `ci` for automation.

Write the summary in English, use the imperative mood, begin with a lowercase letter, omit the trailing period, and keep it concise—preferably no more than 72 characters.

Examples:

```text
docs: add initial profile README
docs: refine project descriptions
chore: establish repository conventions
ci: add markdown link checking
```

## Pull Requests

- Explain what changed and why.
- Review the rendered Markdown before merging.
- Verify that links work and project descriptions remain accurate.
- Confirm that no private or sensitive information is included.
- Squash merge completed pull requests and delete their branches.

## Profile Content Guidelines

- Keep the profile concise, factual, and written from a contributor's perspective.
- Do not imply ownership of organizations or projects beyond the author's actual role.
- Keep project descriptions aligned with the current scope of their repositories.
- Do not publish private contact details or other sensitive information.
- Prefer stable, first-party links.
- Avoid visitor counters, dynamic statistics, tracking images, and badge clutter unless they provide clear value.
