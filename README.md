# Hi, I'm Jiacheng Huang 👋

I work on AI infrastructure, domain-specific languages, and high-performance operator and runtime systems. My current focus is making deep-learning workloads easier to optimize and deploy across GPUs and diverse AI accelerators.

I contribute to several open-source projects in the [InfiniTensor](https://github.com/InfiniTensor) organization, including:

- [NineToothed](https://github.com/InfiniTensor/ninetoothed) — a domain-specific language that uses tensor-oriented meta-programming to make high-performance GPU kernels easier to write.
- [InfiniOps](https://github.com/InfiniTensor/InfiniOps) — a high-performance, cross-platform operator library supporting multiple GPU and AI-accelerator backends.
- [InfiniRT](https://github.com/InfiniTensor/InfiniRT) — a runtime library providing a unified entry point for device management, memory operations, and other accelerator runtime capabilities.
